# Firework Show

Welcome to the **Firework Show** created by Sayn Achhava! This project showcases a vibrant, interactive fireworks display in your browser. Explore the options to customize your experience and enjoy the show!

## Overview

This project includes an HTML file that sets up the structure and functionality for a fireworks display. The display includes interactive elements such as controls for pausing, sound, and settings. 

## Features

- **SVG Icons**: Custom icons for controls such as play, pause, sound, and settings.
- **Dynamic Canvas**: Two canvas elements for rendering the fireworks display.
- **Interactive Controls**: Buttons for controlling the display and adjusting settings.
- **Settings Menu**: A comprehensive settings menu to customize various aspects of the fireworks show.
- **Help Modal**: A help modal for user assistance.

## Files

- `index.html`: The main HTML file containing the structure and setup.
- `style.css`: Custom styles for the display and controls.
- `script.js`: JavaScript code for managing the fireworks display and interactions.

## Setup

To view the fireworks show:

1. **Clone the Repository**:
   ```sh
   git clone https://github.com/eriskcn/firework.git
   ```

2. **Navigate to the Project Directory**:
   ```sh
   cd firework
   ```

3. **Open `index.html` in Your Web Browser**.

## Features

- **Loading Screen**: Displays while the fireworks show is being set up.
- **Canvas Elements**: For rendering the fireworks effects.
- **Controls**: 
  - **Pause/Play**: Control the fireworks display.
  - **Sound**: Toggle sound effects on and off.
  - **Settings**: Adjust settings for shell type, size, quality, and more.
- **Settings Menu**: Allows customization of the display, including auto-launch, finale mode, and fullscreen options.
- **Help Modal**: Provides additional information and assistance.

## Customization

You can modify the following settings through the provided settings menu:

- **Shell Type**: Choose different types of fireworks shells.
- **Shell Size**: Adjust the size of the fireworks.
- **Quality**: Change the visual quality of the fireworks.
- **Sky Lighting**: Modify the lighting effects in the background.
- **Scale**: Adjust the scale of the fireworks display.
- **Auto Fire**: Enable automatic firing of fireworks.
- **Finale Mode**: Activate a special finale mode for an enhanced experience.
- **Hide Controls**: Option to hide or show controls during the display.
- **Fullscreen**: Toggle fullscreen mode.
- **Open Shutter**: Enable long exposure effects for a different visual effect.
